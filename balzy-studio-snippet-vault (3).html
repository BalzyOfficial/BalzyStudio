Analisis file secara statis
File diperiksa di browser dan tidak dijalankan atau diunggah ke server. Pemeriksaan ini bersifat heuristik, bukan pengganti antivirus atau sandbox profesional.





Belum ada analisis.


Batasan penting: browser tidak dapat menjamin deteksi ransomware, fullscreen lock, atau semua nomor telepon tersemat hanya dengan pencarian string. APK adalah arsip ZIP; untuk membongkar manifest/DEX secara benar dibutuhkan parser khusus. Analisis ini mencari indikator sederhana dari nama file dan string yang terbaca. File diproses lokal; tombol clear menghapus referensi file dari halaman.

Status konfigurasi Firebase

   
Konfigurasi Firebase sudah tertanam di Balzy Studio. Jika koneksi gagal, pastikan Authentication Anonymous aktif dan Security Rules Firestore sudah dipublikasikan.

   
   
   

   
Akun anonim baru dibuat otomatis setelah konfigurasi berhasil dan chat pertama kali dibuka.

   
Tampilkan Firestore Security Rules
Tempel rules ini di Firebase Console → Firestore Database → Rules lalu Publish. Tanpa rules yang sesuai, chat tidak akan dapat membaca/menulis pesan dengan aman.

   
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read: if request.auth != null && request.auth.uid == uid;
      allow create, update: if request.auth != null && request.auth.uid == uid;
      allow delete: if false;
    }
    match /globalMessages/{messageId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.text is string
        && request.resource.data.text.size() > 0
        && request.resource.data.text.size() <= 500
        && request.resource.data.username is string
        && request.resource.data.username.size() <= 24
        && request.resource.data.createdAt == request.time;
      allow update, delete: if false;
    }
  }
}
